# Sonic Animation Viewer 개발 문서

## 1. 프로젝트 개요

`sonic-sprite.png`에 포함된 Sonic의 여러 동작을
순서대로 재생하는 애니메이션 뷰어를 제작한다.

Python과 pico2d를 사용하며 프로그램은
`sonic_animation_viewer.py` 하나의 파일로 작성한다.


## 2. 개발 환경

- Language: Python
- Library: pico2d
- 실행 파일: `sonic_animation_viewer.py`
- Sprite Image: `sonic-sprite.png`
- Canvas Size: 1200 x 600


## 3. 스프라이트 구성

- `sonic-sprite.png`에 포함된 Sonic의 동작을 사용한다.
- 총 10종의 애니메이션 동작을 사용한다.
- 전체 프레임 수는 총 76프레임이다.
- 각 애니메이션의 프레임은 이미지에서 필요한 영역을 잘라 사용한다.
- 각 프레임의 위치와 크기는 실제 스프라이트 이미지를 기준으로 정의한다.


## 4. 애니메이션 출력

- Sonic의 스프라이트는 원본 프레임 크기의 4배로 출력한다.
- 프레임의 원래 가로/세로 비율을 유지한다.
- 애니메이션이 재생될 때 프레임이 순서대로 변경되어야 한다.


## 5. 애니메이션 반복

각 동작은 다음 순서로 실행한다.

1. 현재 동작의 애니메이션을 재생한다.
2. 해당 동작을 총 5회 반복한다.
3. 5회 반복이 끝나면 마지막 상태에서 1초 동안 정지한다.
4. 1초가 지나면 다음 동작으로 변경한다.


## 6. 전체 애니메이션 순환

- 10개의 동작을 순서대로 실행한다.
- 마지막 동작의 재생이 끝나면 다시 첫 번째 동작으로 돌아간다.
- 프로그램이 종료될 때까지 전체 동작을 계속 반복한다.


## 7. 이동 애니메이션

이동이 포함된 동작은 프레임 애니메이션만 재생하는 것이 아니라
캐릭터의 화면 위치도 동시에 변경되도록 구현한다.

따라서 이동 동작에서는 다음 두 작업이 동시에 실행된다.

- 현재 애니메이션 프레임 변경
- Sonic의 화면 좌표 변경

프레임 변경과 위치 이동은 실제 경과 시간을 기준으로 처리하여
움직임이 끊어지지 않도록 한다.

### 이동 동작 처리 규칙

- 이동이 필요한 8종의 동작은 애니메이션 재생과 동시에 화면 위치가 변경된다.
- 이동 속도는 프레임 번호가 아니라 실제 경과 시간을 기준으로 계산한다.
- 화면 경계에 도달하면 필요한 경우 이동 방향을 반대로 변경한다.
- 점프가 포함된 동작은 수평 이동과 함께 점프 궤적을 적용한다.
- 이동하지 않는 동작은 화면 중앙에서 재생한다.


## 8. 화면 경계 처리

이동하는 Sonic이 화면의 경계에 도달하면
화면 밖으로 완전히 사라지지 않도록 처리한다.

필요한 동작에서는 이동 방향을 반대로 변경하여
화면 안에서 계속 애니메이션이 재생되도록 한다.


## 9. 점프 동작

점프가 포함된 동작은 프레임 변경과 동시에
Sonic의 위치가 점프 궤적을 따라 움직이도록 구현한다.

점프 애니메이션이 끝난 뒤에는
다음 동작을 정상적으로 실행할 수 있어야 한다.


## 10. 정지 상태

각 동작을 5회 반복한 뒤 1초 동안 정지한다.

정지 중에는 다음 상태를 유지한다.

- 현재 Sonic의 위치 유지
- 마지막 애니메이션 프레임 유지
- 다음 동작으로 즉시 넘어가지 않음

1초가 지나면 다음 애니메이션을 시작한다.


## 11. 개발 단계

프로그램을 한 번에 완성하지 않고 작은 단계로 나누어 구현한다.

1. pico2d 실행 환경 구성
2. 캔버스 생성
3. `sonic-sprite.png` 불러오기
4. Sonic 한 프레임 출력
5. 원본 크기의 4배 출력 적용
6. 프레임 데이터 작성
7. 하나의 애니메이션 재생
8. 프레임 시간 처리
9. 애니메이션 반복 처리
10. 5회 반복 처리
11. 1초 정지 처리
12. 다음 동작 전환
13. 여러 동작 등록
14. 전체 동작 순환
15. 이동 애니메이션 구현
16. 화면 경계 처리
17. 이동 방향 전환 구현
18. 점프 동작 구현
19. 전체 애니메이션 검증
20. 코드 정리 및 최종 검증

다음 조건을 모두 만족하면 프로그램이 완성된 것으로 판단한다.

- 프로그램이 정상적으로 실행된다.
- `sonic-sprite.png`가 정상적으로 로드된다.
- 10종의 애니메이션이 재생된다.
- 총 76개의 프레임이 올바르게 사용된다.
- Sonic이 원본 프레임 크기의 4배로 출력된다.
- 각 동작이 5회 반복된다.
- 반복이 끝나면 1초 동안 정지한다.
- 정지 중 마지막 프레임과 위치가 유지된다.
- 다음 동작으로 정상적으로 전환된다.
- 마지막 동작 후 첫 번째 동작으로 돌아간다.
- 이동 동작에서 프레임과 위치가 동시에 변경된다.
- 점프 동작이 정상적으로 움직인다.
- 이동 중 Sonic이 화면 밖으로 사라지지 않는다.
- 최소 20회 이상의 단계별 Git 커밋이 존재한다.
