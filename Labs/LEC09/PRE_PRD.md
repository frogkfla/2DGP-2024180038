# Sonic Animation Viewer 요구사항 초안

## 1. 개발 환경
- Python을 사용한다.
- pico2d를 사용한다.
- 프로그램은 `sonic_animation_viewer.py` 하나의 파일로 작성한다.
- 애니메이션 이미지는 `sonic-sprite.png`를 사용한다.

## 2. 애니메이션 재생
- sonic-sprite.png에 있는 모든 동작을 순서대로 재생한다.
- 캐릭터는 원본 이미지 크기의 4배로 출력한다.

## 3. 동작 반복
- 각 동작은 5회 반복한다.
- 한 동작을 5회 반복한 후 1초 동안 정지한다.
- 정지가 끝나면 다음 동작을 재생한다.

## 4. 전체 반복
- 마지막 동작까지 재생한 후 다시 첫 번째 동작으로 돌아간다.
- 모든 애니메이션은 무한 반복한다.

## 5. 개발 과정
- 기능을 한 번에 구현하지 않고 단계별로 구현한다.
- 각 단계의 작업 내용을 Git 커밋으로 남긴다.
- 최소 20회 이상 커밋한다.
